# ☁️ Cloud Cost Monitor

Real-time Azure vs AWS pricing comparison dashboard built with Python & Flask.

## 🚀 Features
- Compare Azure and AWS service prices side by side
- Filter by category: Compute, Database, Storage, Serverless, Containers
- Visual bar chart comparison
- Detailed pricing table

## ⚙️ How to run

```bash
# Clone the repo
git clone https://github.com/dabidpq/cloud-cost-monitor.git
cd cloud-cost-monitor

# Create virtual environment
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

Open your browser at `http://127.0.0.1:5000`
